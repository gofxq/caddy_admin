# 完整观测与排障设计

用户要求按 `.archive/metrics.md` 实现完整版本，并明确选择 P0–P3 全部范围，再次要求继续实施。本设计据此连续实施，复用已交付的服务详情与手动 TCP 检查。

## 交付

- P0：固定服务标签的 Caddy 指标、15 秒采集、Counter/Histogram 增量、独立 SQLite、15s/1m/5m/1h/1d 聚合；概览 24h 请求、请求/响应体流量、5xx、P95，以及流量趋势页。
- P1：服务详情增加历史统计、日志、诊断入口；复用绑定发布 ID 和安全地址快照的 TCP 检查。
- P2：Caddy JSON 脱敏日志，经受保护 Admin API 索引到 SQLite，按服务、状态、方法、路径和脱敏 IP 过滤，轮转与保留上限。
- P3：DNS、CAA、TLS、ACME 分类诊断；站内上游连接失败、5xx、延迟和证书到期告警；后台 TCP 检查显式启用，通知仅在站内显示。

## 指标与安全

v2.11.3 的 `per_host` 将未登记 HTTPS Host 独立标记，不能安全直接启用。内置一个小型 Caddy 观测模块，在生成器选择的业务路由和访问限制路由记录固定服务 ID/hostname 标签；不采集控制台、未知 Host 或自动跳转。此项替代提案中的原生 `per_host`，并在 `/metrics` 暴露 Prometheus 指标。方法和状态按有限集合控制标签，Histogram 不带方法/状态标签。

默认关闭 metrics、访问日志、告警和后台检查。开关是设置草稿，必须走既有预览、真实校验和确认发布；不变更历史 JSON 或启动快照。外部 Caddy 需安装同一模块，采集器只读固定 Admin API，不自动配置远端，不跟随重定向，HTTPS 校验信任链。

独立 `${DATA_DIR}/observability.db`，0600，WAL，最大 256 MiB；不得进入 readiness。响应上限 8 MiB、原始指标 series 上限 30000、业务服务上限 500。异常返回未知/缺口，不阻断核心管理。按原始 series 和进程 epoch 判断重置；发布期间或运行漂移时清除基线，保留缺口，服务归属来自成功发布的 ID+Host，不能用草稿或当前域名重新归属历史。Histogram 存储 bucket/count/sum 增量，查询合并后计算分位数，不平均分位数。

请求量统计完成的业务请求，包括访问策略拒绝的 403；流量仅含请求/响应体，非网卡流量。时长包含完整响应；长连接关闭前不会进入完成统计。首字节时长单独记录。分位数为固定 bucket 插值估算，最高有限 bucket 之外显示下界。采集失败、重启、发布与日志溢出需显示数据不完整。

## 历史与日志

每次增量事务写入五级聚合。15s 保留 1h、1m 保留 7d、5m 保留 30d、1h 保留 180d、1d 保留 365d；查询自动选择可用分辨率，至多 1000 点，不足数据不补零。清理有固定批量和时间预算。核心 schema v7 保持不变，设置 JSON 保存新增可选开关。

日志只记录 service ID、已登记 Host、时间、规范化方法、状态、时长、体字节数、路径与脱敏 IP。不记录 query、headers、Cookie、Authorization、body、原始异常；路径可含敏感段，默认仅保存 `/` 与一级路径分类，IP 保存 IPv4 /24 或 IPv6 /48 网络，查询对应脱敏值。写文件前脱敏。Caddy 有限异步队列，不阻塞代理；日志文件 16 MiB，保留一份轮转，源文件 0600，索引保留 7d/100000 条。游标包含 epoch 与序号，重试去重，溢出明确报告缺口。

ACME 操作日志编码器只提取分类，丢弃原始 message/fields，分类包括限速、DNS 授权、CAA、签发未知失败，绝不返回原始模块日志。未知分类不能宣称具体根因。

## 诊断与告警

管理员手动 DNS/CAA 检查只接受 domain ID，使用已生效注册域名和配置 DNS；展示网络视角及未知状态。TLS 复用固定 Caddy 地址探测。ACME 分类来自脱敏事件，仅作为历史线索。

告警使用完整的近 5 分钟观测窗口，至少 20 请求，5xx >=10% 或 P95 >=2 秒；低流量/缺口为未知，不误报正常。证书到期阈值 30 天。可选后台 TCP 检查仅访问已发布已校验快照，沿用当前许可和运行核对，连续三次失败告警；Manager 与外部 Caddy 的网络视角不同。告警记录首次/最近发现及恢复，站内确认不阻止继续发现。

## 验证与交付边界

覆盖固定标签、未知 Host、403、成功请求、上游错误、重载/重启、Histogram、Counter 重置、断采、服务 ID 复用、存储故障、游标去重/溢出、写前脱敏、轮转、权限、查询范围、后台探测安全、低流量告警、DNS/CAA 与 TLS 未知。完成 Go race、静态检查、前端测试/类型检查/构建、真实 Caddy 集成；环境允许时进行隔离容器验收。不会使用生产凭据/数据库，也不会发布到真实实例。
