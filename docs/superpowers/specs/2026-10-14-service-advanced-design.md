# 服务高级配置与服务级片段

用户已要求完整实现四项常用选项及服务级配置片段，兼顾美观、易用性和现有安全发布流程。

## 范围与交互

基础区保留名称、域名、上游协议/主机/端口及备注。协议增加 gRPC 明文（h2c）和 gRPC TLS，保留 HTTP/HTTPS。高级区按需展开，提供响应压缩（关闭、gzip、zstd + gzip）、请求/响应头（设置、追加、删除）及连接/响应头超时。默认保持现有 HTTP 行为、关闭压缩、空头规则和 Caddy 默认超时；gRPC 不使用 HTTP 响应压缩。

文本区位于高级配置内，标为「服务级 Caddyfile 片段」，展示支持指令和可插入示例。片段补充表单，重复配置同一压缩/超时/同方向同名头时明确报错，不静默覆盖。提供「检查配置」按钮、检查中/失败/成功状态与有效配置只读 JSON；修改输入使旧结果失效。检查不会保存草稿或改变线上，关闭弹窗时保留既有未保存提醒。所有检查、保存失败保留输入；移动端单列，桌面分组和清晰摘要。

## 片段与安全

支持 `encode gzip` / `encode zstd gzip`、`header`、`request_header`（单行或静态头规则块）、不含上游地址的 `reverse_proxy` 块（`header_up`、`header_down`、`transport http` 中的 `dial_timeout` 与 `response_header_timeout`）。名称、端口、协议和固定 IP 始终来自上游表单及领域安全校验。未知指令、站点块、全局设置、include/import、额外上游、动态变量、文件访问和跳过证书验证拒绝并返回行号。

头部名称按 HTTP token 检查，值禁止控制字符；拒绝 Authorization、Proxy-Authorization、Cookie、Set-Cookie 和常见 API 密钥头，凭据不进入草稿、导出、预览或日志。每方向最多32条头规则，值最多2048字节，片段最多4096字节，正超时最长24小时。请求 Host 可以设置，不改变 TLS 验证对象或固定上游地址。

## 模型与流程

服务 `scheme` 支持 `http|https|h2c|grpcs`，可选 `advanced` 保存结构化字段与原始片段。领域层解析受限语法、校验并合并为有效选项，统一生成 Caddy JSON；保存、导入、发布、回滚均复用，避免把文本作为第二个线上配置入口。

数据库服务/修订/发布已存 JSON，新增可选字段无需 schema 迁移；旧服务缺失字段按原行为解释，不改历史 JSON 或启动快照。Diff按值比较高级字段，序列化/重新读取不能造成伪变更。配置v2保留高级选项与原始片段，旧v2文件仍合法；敏感/未知字段继续拒绝。

新增鉴权、Origin与CSRF保护的 `POST /api/v1/services/check`，绑定当前草稿修订，只读使用当前策略校验输入并生成完整候选，调用真实Caddy验证；返回规范化服务和有效选项，成功不代替发布页15分钟校验。发布校验与DNS重校验、幂等、待核对、快照、在线回滚维持原规则。
