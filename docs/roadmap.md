# 待办与当前限制

当前范围为专用 Caddy、单实例、单管理员的 核心配置管理、多域名管理、证书概览、服务详情与可选观测排障。不支持现网导入、多用户、多实例、多上游、路径路由或任意配置编辑。

## 观测与排障（P0–P3）

已实现可选固定服务标签指标、15 秒采集、五级 Rollup、24 小时概览、独立流量页、服务级趋势与脱敏日志、手动 DNS/CAA/TLS 诊断及站内告警。后台 TCP 为显式开启的限额轮询；四个开关默认关闭，保存草稿后经校验与确认发布启用。

保留单实例、单管理员；导航为「概览、服务、发布、流量、证书、审计、设置」。不新增多上游、路径路由、任意配置编辑、外部监控基础设施或通知系统。观测故障不能阻断登录、发布或 Caddy。

实现使用自有 `caddy_admin_*` 固定标签模块，避免原生 `per_host` 在未知 HTTPS Host 下产生不受控标签；图表复用 React/SVG，不引入 ECharts。外部 Caddy 缺少模块时明确不可用，不自动修改远端。资源和统计边界见[使用指南](usage.md#流量日志诊断与站内告警)、[运维说明](operations.md#可选观测的持久化与维护)。

详见[完整设计](superpowers/specs/2026-10-03-observability-complete-design.md)与[实施记录](superpowers/plans/2026-10-03-observability-complete.md)。原始 [metrics 提案](../.archive/metrics.md)描述目标，具体默认值和边界以当前实现为准。

## 当前流程

普通 Setup 只有「管理员 → 首个域名与 DNS → 确认」三步，服务器 DNS 默认 `1.1.1.1`。凭据可手动输入或通过 Compose/环境预配置后确认使用。没有 LAN/VPN 网段输入或来源设备绑定，控制台来源限制默认关闭。

登录后在设置中选择业务域名访问范围、配置上游许可，并可选择启用控制台 LAN/VPN 限制。设置和服务均保存草稿，统一预览、校验和明确确认发布。DNS 预览、确认写入和浏览器 DoH 检查为独立动作，查询失败可重查，不重复修改记录。
