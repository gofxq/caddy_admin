# 待办与当前限制

当前范围为单实例、单管理员的 P0 与证书概览。首次初始化仅配置 Homelab，Public 域名运行时配置尚未提供；不支持现网导入、多用户、多实例、多上游、路径路由或任意配置编辑。

## 本轮已完成

| 优先级 | 功能 | 当前行为 |
| --- | --- | --- |
| P0 | 自动填写网络 CIDR | 根据服务器看到的私有来源地址，预填可信网络和上游网络：IPv4 `/24`、IPv6 `/64`。可编辑，导入值优先；回环、链路本地、公网或无效来源需手动填写。Docker/NAT 下须核对实际范围。 |
| P0 | 默认 DNS 与快捷选择 | 默认 Cloudflare `1.1.1.1`；提供 DNSPod、阿里 DNS、Cloudflare、Google 快捷选择及自定义 IP/端口。采用传统 DNS，不直接使用 `https://doh.pub` DoH；修改解析器后重新检查 DNS。 |
| P0 | 精简界面文案 | 删除营销口号、装饰性英文副标题与重复导航文案。字段辅助说明支持悬停、聚焦与点击；安全警告、操作影响、错误与确认条件仍直接显示。 |

## 初始化布局更新

Setup 保持多步，导入后集中核对配置。DNS 步骤将地址、Token 和解析器紧凑排列，「确认配置」与「检查 DNS」为两个独立按钮；检查只查询，不重复修改 Cloudflare。结果表显示每个解析器的查询名称、返回地址与检查结果，失败可单独重查。默认解析器为 `1.1.1.1`，导入值优先；最终提交仍强制核对 DNS。
