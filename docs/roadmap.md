# 待办与当前限制

当前范围为专用 Caddy、单实例、单管理员的 P0、多域名管理、证书概览、服务详情与管理员手动 TCP 检查。不支持现网导入、多用户、多实例、多上游、路径路由或任意配置编辑。

## 轻量观测与排障优先级

| 阶段 | 范围 | 状态 / 进入条件 |
| --- | --- | --- |
| A | 服务详情、配置运行核对、最近相关发布、手动 TCP 检查 | 本批实现；不后台周期探测，不修改运行配置 |
| B | 可选 metrics 与少量概览指标 | 未实现；先解决固定 Caddy 版本的 HTTPS Host 基数控制，统一生成器管理配置，经预览、校验和确认发布启用 |
| C | 短期历史趋势、服务级统计 | 未实现；先验收重载计数重置、断采缺口、历史 ID 归属与资源限额 |
| D | 脱敏访问日志 | 未实现；先明确写文件前脱敏、外部日志来源、轮转及容量 |
| E | 周期探测和告警 | 未实现；先明确探测网络视角、未知状态和通知选择 |

保留六项导航，优先在概览和服务详情呈现核心信息。独立流量页面、P50/P99、五级 Rollup 不作为首批交付条件。metrics 评估基线为 30 秒采集、1 分钟聚合、7 天保留，使用独立观测数据库；仍需实测后确定资源预算。观测故障不能阻断登录、发布或 Caddy。

详见[设计](superpowers/specs/2026-10-03-observability-foundation-design.md)与[第一阶段计划](superpowers/plans/2026-10-03-observability-foundation.md)。原始 [metrics 提案](../.archive/metrics.md)为历史规划，不代表已实现功能。

## 当前流程

普通 Setup 只有「管理员 → 首个域名与 DNS → 确认」三步，服务器 DNS 默认 `1.1.1.1`。凭据可手动输入或通过 Compose/环境预配置后确认使用。没有 LAN/VPN 网段输入或来源设备绑定，控制台来源限制默认关闭。

登录后在设置中选择业务域名访问范围、配置上游许可，并可选择启用控制台 LAN/VPN 限制。设置和服务均保存草稿，统一预览、校验和明确确认发布。DNS 预览、确认写入和浏览器 DoH 检查为独立动作，查询失败可重查，不重复修改记录。
