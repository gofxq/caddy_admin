# 待办与当前限制

当前范围为专用 Caddy、单实例、单管理员的 P0、多域名管理与证书概览。不支持现网导入、多用户、多实例、多上游、路径路由或任意配置编辑。

## 当前流程

普通 Setup 只有「管理员 → 首个域名与 DNS → 确认」三步，服务器 DNS 默认 `1.1.1.1`。凭据可手动输入或通过 Compose/环境预配置后确认使用。没有 LAN/VPN 网段输入或来源设备绑定，控制台来源限制默认关闭。

登录后在设置中选择业务域名访问范围、配置上游许可，并可选择启用控制台 LAN/VPN 限制。设置和服务均保存草稿，统一预览、校验和明确确认发布。DNS 预览、确认写入和浏览器 DoH 检查为独立动作，查询失败可重查，不重复修改记录。

## 待验收

真实浏览器、移动端、目标防火墙/NAT、真实 DNS、Cloudflare 签发与续期、加密宿主快照隔离恢复仍需按[验证说明](verification.md)在专用环境验收。自动测试、构建与演示界面不能替代真实部署验收。

schema v7 与导出 v2 明确拒绝旧版本，不提供原地无损升级或自动兼容迁移。本表不承诺范围外功能的实现时间。
