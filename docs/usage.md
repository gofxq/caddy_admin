# 使用指南

Caddy Web Admin 面向专用 Caddy 实例，采用单实例、单管理员模式，不接管现网或导入旧 Caddyfile。界面包括「概览、服务、发布、证书、审计、设置」。安装、DNS 与访问边界见[部署与维护](operations.md)。

## 首次使用

内置正式模式同时配置密码、Token、`SETUP_DOMAIN` 和有效 `SETUP_CADDY_IP` 时，启动后先由服务端 DoH 检查解析，再只读核对所选提供商的 DNS 记录，预检无警告则自动初始化；IP 页面显示后台进度。需要 DNS 变更或警告确认时停留在状态观测页，点击「进入向导处理」后才打开手动向导，详情见[环境预配置](setup.md#环境预配置自动初始化)。已有实例忽略这些首次参数。

普通手动 Setup 只有「管理员 → 首个域名与 DNS → 确认」三个步骤，不填写 LAN/VPN 网段或上游许可，不绑定初始化设备。公网与内网入口均可打开；初始化后控制台来源限制默认关闭，管理操作仍须认证。

管理员密码至少 8 个 Unicode 字符、最多 256 字节。未预配置时可手动输入或安全随机生成；普通手动流程中，部署已配置 `ADMIN_PASSWORD` 或 `CLOUDFLARE_API_TOKEN` 时，对应项只显示状态并要求确认使用，不显示输入框或凭据内容。非空无效值须修正或清空部署值后重建容器。外部与测试模式不使用本地 Token。HTTP 会明文传输手动输入的凭据，建议使用 HTTPS。

DNS 提供商默认 Cloudflare，也可选择 DNSPod（`ID,Token`）。ENV 可预设 `DNS_PROVIDER=dnspod` 与 `DNSPOD_TOKEN`，界面只确认使用，不回显。一个实例使用一个提供商；初始化后沿用保存值，修改 ENV 不会切换。

首个域名可输入 `example.com` 或 `*.example.com`，控制台自动使用 `https://caddyadmin.example.com`。Caddy IP 支持公网或私网，指实际部署入口而非初始化设备来源。DNS 页面按「设置访问地址 → DNS 提供商与凭据 → 检查 DNS 解析」分区；自动配置模式的记录详情默认折叠，手动配置模式默认展开，便于复制记录。普通内置模式先点击「检查 DNS」，浏览器先通过 DoH 核对解析地址，服务器随后只读核对 Cloudflare 的目标域名访问权限、仅 DNS 状态与记录冲突。已有记录符合要求且解析通过后，直接点击「下一步」，无需配置确认或写入 DNS。需要新增或修改记录时才展示变更预览，须明确确认写入，再检查解析；未传播可重查，无需重复写入。浏览器默认 Cloudflare DoH，展开「查询选项」可切换 Google；只发送控制台和随机子域的 A/AAAA 查询。服务器 DNS 高级选项默认 `1.1.1.1`，用于证书校验与诊断，与浏览器 DoH 独立。

预检警告须确认；后台复检变化时保留输入并重新确认。连接失败可重试，503 保留表单，提交结果未知时先核对，不盲目重放。初始化完成、服务端探测通过和用户本机能打开正式入口分别展示；正式入口由用户主动打开。详见[初始化说明](operations.md#初始化与访问边界)。

普通新实例首次登录后可直接添加服务草稿，统一预览、校验与确认发布。首个域名及登录后新增域名默认「允许互联网访问」；控制台来源限制默认关闭。可信与上游网段均为 `0.0.0.0/0`、`::/0`，合法服务名通过独立 `*` 全部许可；受保护目标、全部解析 IP 安全检查及 HTTPS 上游证书验证继续执行。公开服务发布时仍须确认暴露影响，其名称和域名会展示在无需登录的服务导览。

需要仅 LAN/VPN 访问时，在设置中把可信全网段替换为实际可信网段，再启用控制台限制或将业务域名改为「仅可信网络」。仅勾选开关、保留全网段不会收紧访问。上游网段及服务名许可也可按需收窄：名称精确匹配，独立 `*` 许可所有合法名称，不支持其他通配形式；上游网段为空拒绝所有目标，服务名许可为空只允许安全的已许可 IP。已有实例和显式导入不补新默认值；导入的「待配置」域名仍不能发布启用服务。设置保存只改变草稿，须经过预览、校验与明确确认发布才生效。

首次服务列表为空，初始化时显式导入配置除外。添加示例草稿需在维护终端执行：

```bash
docker compose stop caddy
docker compose run --rm --no-deps caddy manager seed-examples
docker compose start caddy
```

源码部署或外部模式使用各自的 Compose 文件组合；示例仅保存草稿，不自动发布。

## 服务与发布

在「服务」中新增、修改、启停或删除服务并保存草稿；这些操作不会立即影响线上。保存后会明确提示尚未上线，可继续添加或前往「预览与发布」。

新建服务只需填写子域名前缀，例如选择基础域名 `example.com` 后填写 `photos`，访问地址自动组成 `https://photos.example.com`。只有一个基础域名时直接展示，多个时可选择；切换域名保留前缀。前缀限一层，不能占用当前或交接中的控制台域名。域名设置尚未读到或读取失败时不能新建，失败可重试；服务列表读取失败不会显示为无服务。

上游主机支持粘贴 `http://10.0.0.8:2283` 或 `https://[fd00::8]:8443`，自动拆分协议、主机与端口；不接受包含凭据、业务路径、查询参数或片段的 URL。切换 HTTP/HTTPS 时，未手动修改的默认端口跟随切换为 80/443；手动填写或粘贴明确指定的端口保留。已有服务的非默认端口也保留。HTTPS 上游仍需校验证书，所有上游仍须通过服务端许可与受保护目标检查。

服务名称最多 100 个 UTF-8 字节，备注最多 2000 字节，表单显示已用字节数；中文通常占 3 字节。超限时保留输入并阻止提交。

编辑服务或设置时，关闭服务弹窗、切换页面或刷新会提醒尚未保存的修改。请求失败时保留表单；修订冲突可点击「读取最新草稿」或「读取最新设置」，核对最新内容后选择「已核对，保留输入继续编辑」，再自行保存。此操作不会自动重试提交；服务已被删除或所属域名已移除时，先保留所需内容，再关闭编辑器从最新列表处理。

首次运行任务以实际服务列表判断是否已创建服务；仅发布设置不会结束引导，已有启用服务成功发布后才隐藏任务中心。

点击服务名称进入详情，分别查看草稿、已发布配置及其域名访问范围。已从草稿删除但尚未发布删除的服务，可从列表下方「待发布删除」进入详情；线上路由在明确发布删除前仍保留。详情按服务 ID 关联，不会把同域名重建的另一服务混为一体。

「运行配置核对」检查完整 Caddy 配置是否与已发布版本一致，不代表上游应用健康。Caddy 不可达显示未知；有正在执行或待核对的发布时提示到发布页面处理；配置漂移需核对后重新校验和明确确认。断联时仍显示已读取的配置，点击「刷新详情」重试。

详情中的「检查已发布上游」仅由管理员点击后执行：从 Manager 对已发布、启用服务的固定 IP 地址快照建立 TCP 连接，最长等待 3 秒，不访问草稿目标，不重新解析上游名称，也不修改配置。TCP 可连接不代表 HTTP 应用正常或 HTTPS 证书有效；外部模式中 Manager 与 Caddy 的网络可能不同。网络拒绝提示检查监听、网络和防火墙，超时或检查期间发布变化显示未知；刷新详情后可重试。全实例同时最多一个检查，不后台周期检查，不持久化检查结果。

最近相关发布展示最近 20 次全局发布中涉及此服务 ID 的最多 5 条记录；它不是完整服务历史，完整记录仍在「发布」中查看。

在「发布」中查看业务 Diff 和只读 JSON，校验配置，核对影响后明确确认发布。校验有效期为 15 分钟；草稿、策略、DNS 或运行指纹变化后必须重新校验。

发布页的「完整 Caddy 配置」提供三个标签：

- **发布前对比**：将本次读取的实际运行配置与待发布候选对比。默认桌面并排展示，支持切换统一视图；删除为红色 `−`，新增为绿色 `+`，替换内容进一步高亮，保留两侧行号。手机按行上下排列。长段未修改内容默认折叠，可点击展开或勾选「显示未修改行」。变更特别大时按整块增删展示，配置内容不省略。
- **当前运行配置**：展示从 Caddy Admin API 读取的完整只读 JSON，以及读取时间和完整运行指纹；不是数据库中的上次发布记录。
- **待发布配置**：展示当前草稿生成的完整只读 JSON；回滚时展示按当前策略重新生成的历史业务候选。

JSON 按对象字段名排序以减少格式噪音，数组顺序原样保留。预览默认每 15 秒刷新，也可点击「刷新预览」；校验成功后视图更新为此次校验的配置。刷新失败时保留上次成功读取的内容并明确标记过期，不能继续发布，须刷新并重新校验；首次读取失败不使用历史配置代替。

预览保留管理接口、存储及业务配置结构，密码、Token、私钥等敏感值由服务器替换为 `[REDACTED]`，可展开查看 JSON Pointer 脱敏位置。未知管理接口、存储或扩展模块的参数按保守规则隐藏；这些 JSON 不能直接用于恢复。对比只覆盖可见内容，完整指纹仍按未脱敏配置计算；可见内容相同而指纹不同时会提示核对，不能据此认为没有线上差异。

发布在后台执行，关闭页面不会取消。网络失败时先核对部署状态；`uncertain` 表示实际运行状态待核对，不能直接重试。审计记录用于追溯操作与草稿历史。

## 服务高级配置

新建或编辑服务时，可选择 HTTP、HTTPS、gRPC 明文（h2c）或 gRPC TLS（grpcs）。客户端仍从业务域名的 HTTPS 入口访问；协议选择控制 Caddy 到上游的连接。HTTPS 和 gRPC TLS 始终验证上游证书，主机名用于 SNI 与证书核对；手动端口不会因切换协议而改变。

展开「高级配置」可快速设置：

| 选项 | 用途与默认行为 |
| --- | --- |
| 响应压缩 | 默认关闭，可选 gzip 或 zstd + gzip，由客户端协商；适用于文本响应。gRPC 消息压缩由两端协商，不能同时启用 HTTP 响应压缩 |
| 请求头、响应头 | 设置、追加或删除静态头，例如 `X-App`、`X-Frame-Options`、删除 `Server`；同一方向同名头只配一条 |
| 连接超时 | 例如 `5s`，限制建立上游连接的时间；留空使用 Caddy 默认值 |
| 响应头超时 | 例如 `1m`，限制等待上游响应头的时间；不限制已经开始的流式响应。留空使用 Caddy 默认值 |

WebSocket 和 SSE 沿用 Caddy 的自动代理能力，无需额外开关。请勿在头部或片段中填写密码、Token、Cookie 或其他凭据；常见凭据头会被拒绝。头值仅支持静态文本，不支持占位符。

「服务级配置片段」提供有支持列表的 Caddyfile 语法，可插入示例后修改。它与表单合并，不覆盖表单；重复压缩、超时或同方向同名头会报错，删除其中一处后重试。每条指令单独一行，块使用独立的结束括号。例如以下片段可与未填写相同选项的表单一起使用：

```caddyfile
encode zstd gzip
header {
    X-Frame-Options SAMEORIGIN
    -Server
}
reverse_proxy {
    header_up X-App my-service
    transport http {
        dial_timeout 5s
        response_header_timeout 1m
    }
}
```

支持 `encode gzip` / `encode zstd gzip`、单行或块式 `header` / `request_header`，以及上例中的 `reverse_proxy` 子指令。头规则用 `名称 值` 设置、`+名称 值` 追加、`-名称` 删除；带空格的值使用双引号，支持 `#` 行注释。片段最多 4096 字节，每方向最多 32 条头，单个值最多 2048 字节，超时须大于 0 且不超过 24 小时。不支持站点/全局块、额外上游、匹配器、路径路由、文件导入、环境变量、任意指令或跳过 TLS 验证；上游和访问边界仍由表单及实例策略控制。

点击「检查配置」会使用当前草稿策略校验尚未保存的输入，并调用本地真实 Caddy 检查完整候选；可查看合并后的选项及只读 JSON。即使服务处于停用状态，检查也会临时将它纳入候选。检查不保存、不发布，修改输入后应重新检查。失败保留输入；草稿修订冲突时先读取最新草稿、核对后继续编辑。检查不能证明上游连通、证书有效或外部 Caddy 的模块可用，保存后仍须在发布页校验并明确确认。高级选项和原始片段随业务配置 v2 导入导出，并在在线回滚时按当前策略重新生成。

## 服务导览

访问控制台域名下的 `/portal` 可打开无需登录的「服务导览」，登录页和控制台侧栏也提供入口。页面展示已成功发布且启用的服务，支持按名称或域名搜索，点击卡片在新标签页打开业务 HTTPS 地址。

导览只显示服务名称、域名和访问链接，不展示备注、上游地址或管理配置。它沿用控制台 LAN/VPN 来源限制；不在已发布可信网段中的访客看不到「仅可信网络」服务。进入业务应用后仍须遵守应用自身的登录要求。

保存草稿不会改变导览，成功发布或在线回滚后才更新；草稿中待删除或待停用的服务在成功发布前仍按已发布状态展示。页面每 30 秒及重新聚焦时刷新，也可手动刷新。首次发布前或没有当前网络可见的启用服务时显示空列表；配置操作忙碌、发布执行中、待核对或读取失败时隐藏旧链接并提供重试，搜索内容保留。链接不代表实际运行配置已核对或应用健康。

## 在线回滚

只有成功发布的版本可回滚。回滚按当前网络策略和 DNS 重新生成历史业务配置，保留尚未发布的草稿；失败或待核对的版本不能作为回滚目标。

## 配置导入导出

在「设置」导出域名、网络策略和服务草稿，或上传 v2 文件预览并明确确认替换草稿。现有实例沿用本机域名和网络策略，只替换服务草稿，不自动发布。新实例可在管理员步骤显式采用完整业务配置，核对域名、访问属性、策略和草稿；仍使用同样三个步骤，不增加网段输入。管理员凭据和 Token 由部署预配置确认或手动填写，不从文件导入。导入的控制台来源限制仅保留为待发布草稿，初始化不自动启用。旧 v1 文件明确拒绝。

导出不包含密码、Token、证书、发布历史或运行数据，不能代替完整备份。大小、字段限制、冲突处理与初始化导入边界见[配置迁移](operations.md#配置迁移)。

全生命周期及汇总图见[完整使用流程](product-user-flow-review.md)。当前限制与未完成事项见[待办](roadmap.md)；历史需求、设计和验收记录见[归档](../.archive/README.md)。

## 流量、日志、诊断与站内告警

导航包含「概览、服务、发布、流量、证书、审计、设置」。观测开关默认关闭；在设置中启用指标、脱敏访问日志、站内告警或后台 TCP 检查，保存草稿，再经预览、校验、确认发布后生效。后台 TCP 检查还需要启用站内告警。关闭开关保留已采集历史，不删除业务草稿或发布记录。

- **概览**：最近 24 小时请求量、请求/响应体字节、5xx 与 P95，以及站内告警。
- **流量**：按时间和历史服务 ID 筛选趋势；详情可查看 P50/P95/P99、首字节 P95 和状态码类别。单服务详情展开「运行统计与日志」可直接下钻。删除后重建的同名服务使用新 ID，不继承旧服务统计。
- **脱敏日志**：按服务、状态码、方法、路径分类、IP 网段筛选和分页。写文件前丢弃 query、headers、Cookie、请求体和原始错误；路径只保留固定分类，未知路径为 `/<redacted>`，IP 为 IPv4 /24 或 IPv6 /48 网段。无法搜索原始路径或完整 IP。
- **诊断**：手动选择已发布域名查询 DNS/CAA，并通过固定 Caddy 地址核对 TLS。签发线索只显示 ACME 限速、DNS 授权、CAA、DNS 或原因未确认等类别，不展示原始模块日志。全实例事件不能证明属于选中的域名；Manager 的 DNS/TCP 视角也可能不同于浏览器和外部 Caddy。
- **告警**：每分钟评估。完整 5 分钟至少 20 个请求后，5xx 比例达到 10% 或 P95 达到 2 秒触发；证书不足 30 天或校验异常也会提示。可选后台 TCP 每分钟最多检查 4 个服务，轮询已发布上游，连续 3 次连接失败触发。确认表示已知晓，仍会继续监测；恢复后再次异常为新事件。仅站内提示，无邮件、Webhook 或外部通知。

指标每 15 秒采集。请求量为完成请求，包含业务访问限制产生的 403；控制台与未知 Host 不计入。流量为已读取请求体和已写响应体字节，**不是网卡流量**。长连接关闭后才计入完整响应时长。分位数由 Histogram 插值估算，超出最高有限 bucket 时显示下界。

历史查询按完整聚合桶返回，界面显示实际统计区间；长时间范围的边界会收窄到分钟、小时或天。空窗口、低流量、断采、重载或数据丢弃均不能证明零流量或应用健康。查看覆盖率、最近采集时间和日志缺口提示；观测故障不会阻止登录、草稿或发布。

外部 Caddy 必须包含本项目的观测模块才能提供这些数据。采集只读取已配置 Admin API，不自动安装模块、修改远端配置或回退到内置实例；启用设置仍须用户明确发布。普通 Caddy 缺少模块时观测显示不可用。现有手动 TCP 检查仍可独立使用。
