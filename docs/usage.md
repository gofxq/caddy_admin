# 使用指南

Caddy Web Admin 面向专用 Caddy 实例，采用单实例、单管理员模式，不接管现网或导入旧 Caddyfile。界面包括「概览、服务、发布、证书、审计、设置」。安装、DNS 与访问边界见[部署与维护](operations.md)。

## 首次使用

Setup 按「管理员 → 域名 → 网络 → DNS → 确认」完成初始化；采用导入配置后缩短为「管理员 → 核对配置 → DNS → 确认」。普通内置模式显示 Cloudflare Token、预览、确认配置和检查 DNS；外部模式或 `TEST_TLS=true` 说明为何不使用本地 Token，仍可独立检查 DNS。

网络范围会按服务器看到的私有来源地址建议 IPv4 `/24` 或 IPv6 `/64`，可修改，Docker/NAT 下请核对实际范围。「检查 DNS」由浏览器通过 DoH 查询，默认 Cloudflare，可切换 Google。查询仅在点击按钮时执行，只发送控制台与随机子域的 A/AAAA 查询，不发送密码或 Token。高级设置中的服务器 DNS 默认 `1.1.1.1`，用于证书校验和运行诊断，可填写可信内网 DNS 的 IP/端口。导入配置中的值优先。问号说明支持悬停、键盘聚焦和点击。

内置模式通过 HTTP 80 或 HTTPS Setup 创建管理员、配置 Homelab 域名与网络策略，在 DNS 步骤填写 Cloudflare Token、确认私网 IP，并预览变更。勾选影响确认后点击「确认配置」，立即创建/更新通配符解析，再单独点击「检查 DNS」。结果表显示所选 DoH 查询的控制台与随机一层子域、返回地址及检查结果；所有返回地址符合目标 IP 后继续，未生效时只需重查，不再次写入。更换 DoH 只清空查询结果，域名、目标 IP 或 Token 改变才要求重新预览确认。最终提交由服务器重新预检并核对 Cloudflare 实际记录与确认指纹，不再用普通 DNS 查询阻断初始化。预检警告变化时保留输入，重新展示警告并要求确认。完成后切换 HTTPS，由 Caddy 自动申请和管理证书；HTTP 会明文传输密码与 Token，仅用于可信内网。可信公网证书就绪前可以保存草稿，校验与发布保持禁用。正式控制台地址和临时入口交接方式见[初始化说明](operations.md#初始化与访问边界)。

域名和用户名在当前步骤提示格式问题；可信网络控制访问设备，上游网络控制允许的代理目标。首次连接失败提供「重试连接」，提交结果未知时继续核对，不重复提交。初始化完成后分别展示服务、DNS、HTTPS 状态，由用户打开正式入口，服务端探测通过不代表本机可达。

管理员密码至少 8 个字符，最多 256 字节。初始化与修改密码表单提供「随机生成」按钮，使用浏览器安全随机源生成 20 位密码；生成后显示密码以便保存，可点击「隐藏密码」。修改密码时会同时填写确认栏，生成不会自动提交。

首次服务列表为空，初始化时显式导入配置除外。添加示例草稿需在维护终端执行：

```bash
docker compose stop caddy
docker compose run --rm --no-deps caddy manager seed-examples
docker compose start caddy
```

源码部署或外部模式使用各自的 Compose 文件组合；示例仅保存草稿，不自动发布。

## 服务与发布

在「服务」中新增、修改、启停或删除服务并保存草稿；这些操作不会立即影响线上。

在「发布」中查看业务 Diff 和只读 JSON，校验配置，核对影响后明确确认发布。校验有效期为 15 分钟；草稿、策略、DNS 或运行指纹变化后必须重新校验。

发布在后台执行，关闭页面不会取消。网络失败时先核对部署状态；`uncertain` 表示实际运行状态待核对，不能直接重试。审计记录用于追溯操作与草稿历史。

## 在线回滚

只有成功发布的版本可回滚。回滚按当前网络策略和 DNS 重新生成历史业务配置，保留尚未发布的草稿；失败或待核对的版本不能作为回滚目标。

## 配置导入导出

在「设置」导出域名、网络策略和服务草稿，或上传文件预览并明确确认替换草稿。现有实例沿用自身域名和网络策略，不自动发布；新实例可在初始化时采用导出的完整业务配置：自动读取域名、网络策略与 DNS 解析器，在「核对配置」集中确认；展开「修改导入设置」即可调整，无需逐项重新填写。随后核对当前 Caddy IP，重新设置管理员密码和内置模式的 Cloudflare Token，完成 DNS 预览与最终确认。导入值仍须通过当前服务器的预检，服务仅保存为草稿。

导出不包含密码、Token、证书、发布历史或运行数据，不能代替完整备份。大小、字段限制、冲突处理与初始化导入边界见[配置迁移](operations.md#配置迁移)。
