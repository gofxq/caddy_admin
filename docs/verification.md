# 验证与验收边界

按改动范围选择检查；命令成功仅证明对应范围，不等于真实部署或生产验收。

| 命令 | 验证范围 |
| --- | --- |
| `make test` | Go race 测试与前端 Vitest，不启动浏览器 |
| `make check` | Go vet 与两个 Go 模块的依赖校验 |
| `make build` | Manager 构建、严格 TypeScript 与 Vite 构建 |
| `make integration` | 构建固定 Caddy，验证生成、加载、快照恢复、Cloudflare secret-file，以及服务压缩/头/响应头超时、HTTP/2 gRPC 和上游 TLS 拒绝 |
| `make container-test` | 临时容器中验证环境预配置自动初始化、DNS 人工接续、内置 HTTP 初始化与 HTTPS 切换、外部 HTTPS 初始化、登录、配置导入导出、发布边界、重启与失联处理；需要 Docker、Python、curl |
| `make web` | `127.0.0.1:5177` 演示界面，仅用于界面检查 |
| `make web-demo` | 安装依赖并构建、预览纯静态 Demo（`127.0.0.1:5178`），仅用于界面检查 |

Compose 配置检查：

```bash
docker compose config --quiet
docker compose -f compose.full.yaml config --quiet
CADDY_ADMIN_URL=http://caddy.internal:2019 MANAGER_DIAL=manager.internal:8080 \
docker compose -f compose.yaml -f compose.external.yaml config --quiet
docker compose -f compose.yaml -f compose.validation.yaml config --quiet
```

Setup 自动测试覆盖浏览器 DoH 查询、地址族与通配符、超时与格式错误、无凭据请求、配置/查询状态解耦、连接重试、警告确认指纹与 Cloudflare 记录冲突。DoH 服务的 CORS/CSP、HTTP/HTTPS 实际浏览器访问、真实 DNS 传播和证书签发仍需在专用测试环境验收。

行为变更覆盖主路径、边界、冲突、异常和权限；发布/恢复变更另覆盖断联、崩溃核对及数据保留。测试不用真实 Token、生产数据库或生产 Caddy；`TEST_TLS=true` 仅供隔离夹具，测试 CA 不代表公网信任。

## 服务配置交互回归（2026-10-14）

本轮八项改进记录在 [变更记录](../CHANGELOG.md)，操作方式见[服务与发布](usage.md#服务与发布)。

- `web/src/service-workflow.test.tsx` 覆盖单域名固定后缀、多域名切换与已有服务编辑、一层子域及控制台保留域名拒绝；URL 粘贴拆分、IPv6、显式默认端口与自定义端口保留、敏感 URL 拒绝；UTF-8 字节边界、保存与启停反馈、读取失败与加载中门禁、未保存关闭/导航/刷新提醒，以及 503、修订冲突、并发删除和域名变更时保留输入。
- `web/src/onboarding.test.tsx` 覆盖首个服务创建与上线引导；仅发布设置不结束引导的回归在 `service-workflow.test.tsx`。
- `internal/application/settings_integration_test.go` 的 `TestFirstServiceCanUseUnpublishedUpstreamPolicy` 使用临时 SQLite 与 Caddy 端口替身，验证上游许可草稿与首个服务统一发布、保存不改变线上状态、拒绝受保护目标及保留访问范围确认。

本轮 `make test`（根模块 Go race、Caddy 观测模块 race、前端 189 项）、`make check` 与 `make build` 均通过。受限环境使用可写构建缓存、短路径临时目录和允许本地测试监听端口的执行环境。构建仍有前端单包超过 500 kB 的体积提示。

Vitest 使用 DOM 模拟环境。真实浏览器中的原生离开确认、移动端布局、真实 Caddy 配置加载与目标网络访问仍按下方环境验收要求处理；应用层端口替身测试不能代替真实部署验收。

## 从零手工测试

按[从零测试流程](testing.md)完成空白初始化、现有实例导入导出、重启保留数据和新实例初始化导入，再运行自动检查。

验证项目使用独立命名卷，不读取真实 `.run/`，端口沿用 `compose.yaml` 的映射。需要随机回环端口时，在验证文件中显式覆盖端口，再在宿主浏览器访问或通过受控 SSH 转发访问。`make down` 删除验证项目及其测试卷。内置测试 TLS 模式仍禁止校验与发布，真实证书与业务访问需另行验收。

## 多域名与轻量 Setup 验收

普通 Setup 必须只有三个步骤，不出现网段输入、默认业务访问属性或来源绑定。验证公网/内网来源与公网 Caddy DNS 目标，初始化后默认登录可达但管理 API 必须认证；显式启用控制台来源限制后，Caddy、Manager 和临时入口一致执行，修改业务可信网段不自动启用控制台限制。

使用隔离占位凭据检查密码/Token 两项、单项与均未预配置分支，空值和无效非空值、旧 `setup_id` 拒绝、API 不回显；检查 Compose 明文环境、`.env` 注入及 YAML `$$` 的实际容器传递。重启不得重置密码或以旧环境 Token 覆盖持久化 Token。检查设置草稿和服务共享修订、策略 Diff、未配置访问范围的业务发布阻断、未知 Host 404、仅成功版本回滚保留草稿。schema v6 与 v1 配置文件应明确拒绝并保留原文件。

## 观测验收边界

`make test` 包含根模块 Go race、Caddy 观测模块 race 与前端测试；`make check` 同时检查两个 Go 模块；`make integration` 从当前源码构建真实 Caddy，验证观测配置校验、业务请求 metrics 与脱敏日志、未知 HTTPS Host 不新增标签以及重载 epoch 改变。夹具只使用临时目录、Unix Socket、回环随机端口和内部测试 CA。

自动测试另覆盖 Counter 重置/断采/发布归属、Histogram 插值、五级存储、历史范围边界、服务 ID 不串接、数据库权限、日志去重/持久化游标/首次截断/历史服务恢复、CAA 分类脱敏、低流量和缺口的告警 unknown、确认持久化、会话/CSRF/参数拒绝及前端筛选和诊断交互。

真实浏览器与移动端、长期高负载、宿主磁盘耗尽/写盘卡顿、外部 Caddy 模块安装与网络拓扑、真实 ACME/Cloudflare 签发续期仍需专用环境验收。自动测试不构成这些环境的部署验收。外部通知、原始日志检索和应用 HTTP 健康检查不在本版范围。

## 环境预配置自动初始化验收

Go/application 与 API 测试覆盖必需参数缺失和空白地址、非法非空参数、IPv4/IPv6 安全边界、只读 DNS 复用、变更/双栈警告/冲突/断联、控制台服务器 DNS 缺失仅作提示而允许保存、解析器不可达仍暂停、服务器预检警告、任务重入与手动提交竞争、快照和意图保护、数据库提交响应丢失及进度脱敏。前端测试覆盖后台进度、有效预填、暂停/失败/待核对时保留观测页、刷新不自动进入表单、显式人工接续、逐项预检原因与处理建议、不自动确认凭据及不发送写请求。公开详情只投影已知检查，不包含凭据、域名、IP、解析器列表、内部路径或原始错误。

完整预配置无警告时打开 IP 应直接观察后台初始化并进入交接；参数不足时三步向导，不能用现有 DNS 推断缺失入口地址。首次服务为空，业务上线仍须校验并确认发布。初始化后的参数变化不得重置密码、Token 或线上配置。测试 CA、服务器 DNS 和服务端探测不能误报公网信任或浏览器可达。

隔离容器场景模拟 Cloudflare 与服务器 DNS，仅使用生成的测试 CA、假 Token 和临时数据；运行真实 Manager/Caddy 验证启动自动初始化、IP 进度、HTTPS 登录、重启保留数据及已有实例忽略非法首次参数。它不代表真实 Cloudflare DNS Edit 权限、公网 DNS 传播或 ACME 签发验收，后者仍需专用测试环境。

自动流程与观测页重检测试另覆盖 DoH 优先顺序、A/AAAA、随机通配符探测、NXDOMAIN、问题名不匹配、无关回答、查询失败脱敏与重检并发/旧 setup_id/未决结果拒绝；重检通过也不得创建管理员、写入 DNS、secret 或快照。隔离容器使用本地可信 HTTPS DoH/Cloudflare 模拟，验证重复重检仍只读。服务器 DNS 预检仍独立执行；DoH 正确不证明证书校验解析器可达。

## 默认开放策略验收

普通手动和环境自动初始化均核对：首个域名 `internet`、控制台来源限制关闭、可信与上游网段为 `0.0.0.0/0` 和 `::/0`、服务名许可 `["*"]`、无业务服务及业务路由。新域名默认 `internet`，保存和发布须明确确认影响。

安全公网、私网、VPN、IPv6 IP 及合法服务名应可直接保存草稿；混合安全/危险解析、系统端点、额外禁止 IP 和危险特殊地址仍拒绝，HTTPS 上游仍校验证书，DNS 地址变化须重新校验。清空上游网段拒绝全部目标，清空服务名许可拒绝名称目标；不接受 `*.example.com` 等其他通配形式。

保留全可信网段时启用 LAN/VPN 限制仍可访问，界面必须说明替换实际网段；替换并发布后范围外来源受限。检查匿名导览只显示来源可见的已发布服务。显式导入保留 `null`、空许可或限制策略；配置 v2 支持 `*` 往返。已有实例升级/重启不得改设置、草稿、历史发布和启动快照。继续覆盖认证、Origin/CSRF、公开服务发布确认、断联/崩溃待核对、重启与在线回滚的数据保留。

## 服务高级配置验证边界

领域与 API 测试覆盖片段支持列表、冲突和安全目标、检查权限与只读性、配置 v2 往返及历史保留；前端测试覆盖快捷配置、检查输入失效与失败保留。真实 Caddy 集成测试使用临时回环上游检查 gzip、头规则、响应头超时、h2c/grpcs 的 HTTP/2 帧与 trailer，以及错误 TLS 名称的拒绝。它不等同于公网 gRPC 客户端互通或所有流式应用验收；生产网络、远端模块与真实上游证书仍需部署环境核对。


## 完整配置预览与发布前对比

自动测试覆盖实际运行配置及读取时间、配置漂移、只读预览与校验保留草稿/快照、管理员鉴权与强制改密、Caddy 不可达，以及候选/运行/回滚配置的服务端统一脱敏。脱敏回归包括 ACME EAB 密钥、认证头、内嵌私钥、未知存储与扩展模块、嵌套同名 selector 字段及完整指纹不被显示副本改变。

前端测试覆盖对象字段排序、数组顺序、增删行与双侧行号、行内修改高亮、并排/统一切换、完整 JSON 标签、未修改内容展开、指纹不同但可见 JSON 相同、刷新失败保留旧内容并阻止发布、校验结果替换预览，以及演示发布前后运行配置同步。大范围替换另验证有界对比降级仍能重建两侧全部内容。

本功能已通过 `make test`（根模块 Go race、Caddy 观测模块 race、前端 246 项）、`make check` 和 `make build`。测试在允许隔离回环端口的环境中执行；构建仍有既有的前端单包超过 500 kB 提示。

真实浏览器中的移动布局、键盘导航、长配置滚动和真实 Caddy 读取仍需环境验收；DOM 测试与端口替身测试不能替代真实部署验收。
